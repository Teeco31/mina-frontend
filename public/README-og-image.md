# OG Image Specification

Place a file named `og-image.jpg` in this `/public` directory.

## Required specifications

| Property | Value |
|---|---|
| Filename | `og-image.jpg` |
| Format | JPEG (JPG) |
| Dimensions | **1200 × 630 px** |
| File size | Under 500 KB |
| Colour space | sRGB |

## What to include

- A high-quality photograph of the hotel exterior, lobby, or a signature room
- Mina Hotels logo overlaid in the top-left or bottom-left corner
- The text "Mina Hotels · Port Harcourt" in the Playfair Display font, white, over a dark gradient
- A subtle dark gradient at the bottom to ensure text legibility

## Where it is used

This image appears as the preview image when sharing Mina Hotels links on:
- WhatsApp
- Twitter / X
- Facebook
- LinkedIn
- iMessage link previews

It is referenced in `app/layout.tsx` under `openGraph.images` and `twitter.images`.
